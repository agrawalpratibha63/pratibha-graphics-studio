# Pratibha Graphics Studio

Personal graphics portfolio vault for **Pratibha Agrawal** — logos, YouTube thumbnails, social posts, wedding invites, and client work (including Damini Art's projects).

## Live demo

**Public app:** https://pratibha-graphics-studio.vercel.app  

**GitHub:** https://github.com/agrawalpratibha63/pratibha-graphics-studio

## Features

- Email/password authentication (Supabase)
- Owner dashboard: upload, visibility, visitors
- Visitor view-only library
- Featured image train on home
- Responsive web (laptop + phone)

## Local development

```bash
npm install
cp .env.example .env   # add your Supabase URL + anon key
npm run dev
```

## Web build

```bash
npm run build:web
```

Output is in `dist/` (ready for Vercel / Netlify).
